作成: 2026-07-03 ／ 対象: 【試作版V2】案件進捗管理シート（中身はV3・ステータス手動版）

> **V3対応版（同日更新）**: 設定は専用シート「自動追加設定」に分離。クライアント名は _m/_d 付きのシート表記。初版が設定シートに書いた内容の修復処理入り。**古いコードを貼った人は、ファイルの中身を丸ごと差し替えて `setupCalendarAutoAdd` をもう一度実行すればOK（修復も同時に走る）。**

## 手順（5分）

1. **Apps Script を開く**
   - いつもの生成スクリプトを入れているプロジェクトを https://script.google.com/home から開く
   - （見つからなければ、試作版V2シートを開いて メニュー「拡張機能」→「Apps Script」でもOK）
2. **ファイルを追加**
   - 左の「ファイル」の＋ →「スクリプト」→ 名前は `カレンダー自動追加` など
   - `カレンダー自動追加スクリプト.gs` の中身を全部コピーして貼り付け → 保存（⌘S）
   - ※シートIDは埋め込み済みなので書き換え不要
3. **セットアップ関数を1回実行**
   - 画面上部の関数選択で ↓ を選んで「実行」

   ```
   setupCalendarAutoAdd
   ```

   - 初回はアクセス許可のダイアログが出るので承認（カレンダー＋スプレッドシート）
   - これで「設定シートのクライアント表」「自動追加ログ」シート「毎朝6時のトリガー」が全部セットされる
4. **動作確認（任意）**
   - 関数選択で ↓ を選んで「実行」するとその場でスキャンが走る

   ```
   autoAddFromCalendar
   ```

   - マスターに行が増えて、「自動追加ログ」シートに処理結果が並べばOK

## Discord通知（2026-07-03追加）

行が追加された朝に、Discordのプライベートサーバーへまとめて1通通知される（追加ゼロの日は通知なし）。⚠撮影日変更・予定削除・一覧外スキップも同じ通知に入る。

**設定手順:**
1. Discordの通知したいチャンネルで「チャンネルの編集（歯車）→ 連携サービス → ウェブフック → 新しいウェブフック」→「ウェブフックURLをコピー」
2. 「自動追加設定」シートの **H7** に `Discord Webhook URL`（この文字のまま）、**I7** にコピーしたURLを貼る
3. スクリプトを最新版に差し替えて保存 → 関数 `testDiscordNotify` を実行（初回は外部接続の許可を承認）→ Discordにテスト通知が届けばOK

## 注意すること

- **初回実行は過去7日〜未来90日の撮影予定が一気に追加されます**（7/4 宮川さん、7/6 DEP、7/8 EmpowerXなど）。手動で作成済みの案件と重複したら、その行の中身だけ消せばOK（ログに何が追加されたか残ります）
- **buildPrototype で試作版V2を作り直したらIDが変わります**。新しいURLの `/d/` と `/edit` の間のIDを、スクリプト冒頭の `AUTO_TARGET_ID` に貼り替えてください
- カレンダーの撮影日が変わったり予定が消えたりしても、シートは自動では書き換えません。「自動追加ログ」と該当行のメモ欄に⚠が付くので手動で直してください
