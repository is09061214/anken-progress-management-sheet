まず、このシートの考え方

細かい計算は、シートが勝手にやってくれます。覚えることはたった3つ。この3つさえ頭に入れば、もう8割わかったも同然です。

1行 = 1本の動画

1つの動画案件が、横一列に並びます。クライアントごとにグループでまとまっています。

締切は自動で逆算

投稿予定日さえ入っていれば、制作・サムネ・CL提出などの締切が自動で計算されます。手入力は不要。

ステータスも自動

「今どの工程か」「遅れているか」も自動表示。あなたが回すのはチェックと差し戻しだけです。

補足：新しい案件を足したいとき

案件の登録（クライアント・タイトル・投稿予定日・担当者）は基本砂田さんが行います。登録直後は「制作着手」前なので、ステータスは「未着手」から始まります。迷ったら砂田さんに確認しましょう。

二人で同時に使うコツ（超重要）

増田さんと岩渕さんが同時に使っても、お互いの画面が干渉しない方法です。これさえ守ればケンカしません。

これはOK（干渉しない）
  • データ入力（チェック・差し戻し・日付）。同時でもOK、両方にリアルタイム反映。
  • 自分専用のビュー（増田担当 / 岩渕担当）で絞り込み。自分だけに反映、相手の画面は変わりません。
これは干渉する（避ける）
  • 表全体を直接 並べ替え・フィルタする → 全員の画面が変わります。
  • 二人が同じビューを共有して触る → ぶつかります。

合言葉は 「絞り込みは “自分の担当ビュー” の中でやる」。これだけ守れば二人同時でも大丈夫。入力（チェック等）はちゃんと両方に反映されるので安心してください。

毎日のルーティン

この流れを習慣にすれば、抜け漏れゼロ。3ステップだけです。

朝

ダッシュボードで「赤」と「黄」をチェック

まず赤（要対応）を潰す。次に黄（もうすぐ）を先回り準備。情報不足のリストも見て、入力モレを埋める。

随時

工程が進んだら、その都度 チェックを入れる

制作着手 → 制作✓ → サムネ✓ → CL提出✓ → CLチェック → 公開設定✓。こまめな更新がコツ。

修正

修正が入ったら「差し戻し」＋「修正締切」

チーム修正／CL修正を選び、戻り目安日を入れる。直ったら差し戻しを空に戻す。

やってはいけないこと

これだけ気をつければ、シートが壊れません。

グレーの列を手で書き換えない

各締切と現在ステータスは自動（数式）。直接入力すると壊れます。

投稿予定日を空にしない

ここが空だと締切もステータスも出ません（基本は砂田さんが入力します）。

表を二人で同時に並べ替えない

絞り込みは自分の担当ビューの中で。直接の並べ替えは全員に影響します。

もし「列を消しちゃった」「数式が壊れた」など困ったら、自分で直そうとせずITARUさんに連絡を。すぐ復旧できます。
