## レビュー結果（2026-09-07・業務効率化と工数削減の観点）

### 結論

「監視と通知」はよく自動化されている。人の手が残っているのは
**入口（案件の誕生直後）／状態の更新／壊れたときの復旧** の3か所。効果が大きい5つ:

1. 自動追加された行が全部「灰（情報不足）」になる問題の解消（制作担当の既定値＋灰の細分化）
2. 締切超過の名指しリマインダーを「未着手・タイトル待ち」だけでなく全ステータスに拡張
3. 数式を「1行1数式」から「列ごと1本の数式（ARRAYFORMULA）」に変え、毎朝の修復・破損チェックを不要にする
4. 撮影日の変更を「通知だけ」から「着手前の行なら自動で書き換え」に
5. スプレッドシートにカスタムメニューを付け、BOが自分で「自動計算に戻す」「今すぐ取り込み」できるようにする

前提: 見たのはこのリポジトリの Apps Script 11本・通知スクリプト・ガイド3種。本番シートの中身（実際の行数や設定値）は未確認。

### 1. 人手が残っている場所と改善案

**A. 案件の入口（自動追加の直後）**
- 自動追加は制作担当（K列）を入れないのに、信号は制作担当が空だと灰にする → 撮影のたびに灰が量産される。対策: 「自動追加設定」に「制作担当既定」「サムネ担当既定」を追加／「タイトル待ち」は灰ではなく「未アサイン」の別枠に出す
- サムネ担当が全件未入力の前提（V9のコメント）。サムネ工程のボールが誰にも当たらない → 「空欄なら制作担当と同じ」を数式で補う
- クライアント表が「設定」（締切日数）と「自動追加設定」（本数・曜日・BO・別名）の2か所にある → 1つのクライアントマスターに統合（表記ゆれ修復スクリプトが3本作られた根本原因）
- 撮影日の変更・削除は「⚠通知して人が直す」 → ステータスがタイトル待ち・未着手の行は自動で撮影日・投稿日を書き換える。作業開始後の行だけ従来どおり通知
- 手動で行を足す案件（_d 直接依頼など）は22列を手入力 → 必須5項目だけ入れる「新規案件追加」サイドバー

**B. 状態の更新（ステータスのプルダウン）**
- 編集者が更新できる場所がない（担当者ビューは数式の読み取り専用） → 担当者ビューに「次へ進める」チェック列を置き、onEdit でマスターに書き戻す
- 修正締切は毎回手入力 → 「修正中」にした日＋設定日数（例3日）を自動入力、上書き可
- ステータスを変えた日時が残らない → onEdit で「最終更新日時」「変更者」を隠し列に記録。滞留日数・CL確認中の自動催促・実績分析の土台になる

**C. 締切超過の名指しリマインダー**
- 現状は「未着手」「タイトル待ち」だけ。サムネ待ち超過・砂田確認中超過・アップロード待ち超過は名指しされない → 設定シートのステータス表（S〜U列）の「締切工程」「ボール」を読み、全ステータスで現在の担当をメンション
- 同じ案件が最大30日毎朝同じ文面 → 1日目担当／3日目からBO／7日目からITARUさん、の段階エスカレーション

**D. 復旧作業（ITARUさんへの依頼が出る箇所）**
- 信号系4列（B/T/U/V）が1行ずつの数式で、行移動で壊れる。毎朝5時の修復と7時の破損チェックが必要になっている → ARRAYFORMULA 化で行を動かしても壊れず、朝の処理が2本減る（Table 機能との相性は要検証）
- 締切の手入力が数式を消す → 「手動締切」列を分離し、実効締切＝手動があれば手動、なければ自動
- BOが自分で実行できる操作がない → カスタムメニュー（今すぐ取り込み／自動に戻す／通知テスト／数式チェック）

### 2. 通知と仕組みのムダ

- @everyone が多い（朝通知・自動追加・月曜撮影予定） → 全体向けはBOロールだけ、編集者には個人メンションのみ
- 朝の通知に「今日やること」がない（件数画像＋リンク2本） → 赤・黄の上位数件を担当名と行への直リンク付きで本文に
- 朝の処理が4つの別トリガーで順番が保証されない（自動追加が遅い日は朝通知に含まれない） → 1本の「朝の司会役」関数から順に呼ぶ
- Web ダッシュボードが最大60分古い → 朝の処理の最後に `/refresh` を1回叩く
- 朝通知だけ GitHub 経由で部品が多い（トークン1年失効・Actions・Python・フォント） → Apps Script から直接送れば故障点が3つ消える。画像が必要なら Cloud Run に画像生成だけ残す折衷案
- 列番号の決め打ち（自動追加の COL、リマインダーの K=11/L=12/R=18） → ヘッダー名で列を探す方式に
- 完了行が溜まり続ける（空き行不足エラー・再計算が重い） → 月次アーカイブ＋空き行の自動追加
